# Витрина лендингов

Три демо-лендинга для малого бизнеса в разных стилях. Каждый держится не на картинках, а на интерактиве: живая схема, конструктор, квиз, калькулятор. Всё нарисовано кодом (SVG и CSS), без фото, фреймворков и сторонних JS-библиотек.

| Сайт | Ниша | Стиль | Главный интерактив |
|---|---|---|---|
| [Аптайм](it-office/) | IT-обслуживание офисов | Dev-Clean: тёмная тема в духе JetBrains, светлая — Android Developers | Живая карта сети: мониторинг замечает сбой, лог показывает починку |
| [Стебель](flowers/) | Цветочная мастерская | Ризография: флуоресцентные краски, растр, сбитое совмещение слоёв | Конструктор букета: цветы появляются на схеме, цена считается сразу |
| [Зелёная волна](driving-school/) | Автошкола | Дорожные указатели, разметка, светофоры | Квиз по билетам ПДД, калькулятор с рычагом КПП, машина едет вдоль страницы |

## Что есть в каждом

- Светлая и тёмная тема плюс режим «как в системе». Смена темы — круговое «проявление» от кнопки (View Transitions API).
- Адаптив от 360 px.
- Анимации учитывают настройку «уменьшить движение» (`prefers-reduced-motion`).
- Форма заявки: маска телефона, проверка полей, защита от ботов (honeypot), защита от двойной отправки.
- Тяжёлые анимации работают, только пока блок на экране.

### Аптайм
- Карта офисной сети: пакеты бегут по линиям, раз в несколько секунд случается «сбой», терминал печатает, как его чинят.
- Вкладки услуг с автопереключением: полоса-индикатор заполняется, у каждой вкладки своя мини-анимация (чек-лист, спидометр, бэкап, журнал защиты).
- Калькулятор тарифа по числу рабочих мест, карточки с подсветкой под курсором.
- Линия этапов прорисовывается при прокрутке, счётчики, бегущая лента клиентов.

### Стебель
- Букет в первом экране собирается из отдельных красочных слоёв и чуть расходится за курсором.
- Конструктор букета: цветы раскладываются по спирали с золотым углом, есть выбор упаковки, итог уходит в форму заказа.
- Каталог с фильтром и FLIP-анимацией, курьер едет по маршруту при прокрутке.
- Стопка отзывов, которую можно листать перетаскиванием. После заказа разлетаются лепестки.

### Зелёная волна
- Дорога в первом экране ускоряется от прокрутки, при замедлении у машин загораются стоп-сигналы.
- На широком экране вдоль страницы идёт дорога, машина спускается по ней вместе с прокруткой, остановки — разделы.
- Квиз по ПДД со светофором-прогрессом, калькулятор с анимированным рычагом КПП и рассрочкой.
- Группы с обратным отсчётом до старта, кнопки-светофоры, «финиш» после отправки формы.

## Как перенастроить под клиента

Шаблоны сделаны так, чтобы их можно было быстро отдать новому заказчику:

1. `<сайт>/config.js` — название, телефон, почта, Telegram, адрес приёма заявок. Для цветов и автошколы там же ассортимент, цены и группы.
2. `<сайт>/style.css`, блок `:root` — цвета и шрифты обеих тем.
3. Тексты — в `index.html` сайта.

Заявки: если `endpoint` в `config.js` пустой, форма работает в демо-режиме. Для боевого режима укажите адрес функции из проекта [landing-demo](https://github.com/ZniKDK/landing-demo): заявка уходит в Telegram, запасной канал — почта.

## Структура

```
index.html          витрина с живыми превью всех сайтов
shared/
  base.css          сброс стилей, доступность, служебные классы
  theme.js          переключатель темы
  motion.js         помощники анимаций (появление, счётчики, прокрутка, аккордеон)
  form.js           форма заявки
  site.js           подстановка данных клиента из config.js
it-office/          Аптайм
flowers/            Стебель
driving-school/     Зелёная волна
```

## Запуск

Нужен любой статический сервер, например:

```bash
python -m http.server 8091
```

Затем откройте http://localhost:8091.

## Лицензии

Шрифты из Google Fonts под лицензией OFL: Onest, JetBrains Mono, Yeseva One, Golos Text, Geologica. Компании, люди и отзывы вымышлены.
